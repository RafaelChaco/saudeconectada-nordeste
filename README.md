# SaúdeConectada Nordeste

Projeto acadêmico desenvolvido para o case SaúdeConectada Nordeste.

O objetivo do MVP é criar um módulo simples de prontuário eletrônico para registro de atendimentos médicos, considerando médicos sob estresse, conectividade instável e necessidade de velocidade no preenchimento.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Python
- Flask
- JSON
