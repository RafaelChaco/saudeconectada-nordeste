# Diagnóstico do Problema

O projeto SaúdeConectada Nordeste foi pensado para apoiar profissionais de saúde em regiões com infraestrutura limitada, conectividade instável e alta demanda de atendimento.

## Problemas identificados

- Dificuldade para registrar atendimentos rapidamente.
- Risco de perda de informações clínicas importantes.
- Necessidade de uma interface simples para médicos sob pressão.
- Possibilidade de funcionamento inicial com armazenamento local em JSON.
- Necessidade de futura evolução para banco de dados.

## Solução proposta

Criar um MVP de prontuário eletrônico simples, com:

- Cadastro de paciente.
- Registro de queixa principal.
- Registro de sinais vitais.
- Consulta de prontuários cadastrados.
- Exclusão de registros.
- Backend em Flask.
- Frontend em HTML, CSS e JavaScript.

## Justificativa técnica

A escolha por Flask, HTML, CSS, JavaScript e JSON permite criar uma solução leve, simples de rodar localmente e fácil de demonstrar em ambiente acadêmico.
